# boltlist

Bolt URLs and list query parts with stable normalization.

**Site:** https://theworker02.github.io/boltlist/

## Install / run

```bash
git clone https://github.com/theworker02/boltlist.git
cd boltlist
node src/cli.js
node --test
```
